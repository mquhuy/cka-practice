# Scenario 02: Multi-Container Pods - Q&A

## Questions & Answers

### Q: How to create multi-container pod?
**A:** Use YAML with `--dry-run` approach:
```bash
# 1. Generate template
kubectl run sidecar --image=nginx:alpine --restart=Never --labels=app=sidecar --dry-run=client -o yaml > sidecar.yaml

# 2. Edit to add second container + volume
# - Add second container under spec.containers
# - Add volume under spec.volumes
# - Add volumeMounts in both containers

# 3. Apply
kubectl apply -f sidecar.yaml
```

---

### Q: What does `--dry-run=client` do?
**A:** Generates YAML without creating:
```bash
# Without - creates pod
kubectl run foo --image=nginx

# With dry-run - prints YAML only
kubectl run foo --image=nginx --dry-run=client -o yaml

# Save to file
kubectl run foo --image=nginx --dry-run=client -o yaml > foo.yaml
```

---

### Q: Why `--dry-run=client` vs `--dry-run=server`?
**A:** Where validation happens:
- `client` - kubectl validates locally (fast, default)
- `server` - API server validates (slower, rare)

---

### Q: Why `kubectl run --node-selector` doesn't exist?
**A:** Imperative `kubectl run` doesn't support `--node-selector`. Use:
```bash
# Method 1: overrides
kubectl run prod --image=nginx --overrides='{"spec":{"nodeSelector":{"env":"prod"}}}'

# Method 2: YAML (easier for complex)
kubectl run prod --image=nginx --dry-run=client -o yaml > prod.yaml
# Edit YAML, add nodeSelector
kubectl apply -f prod.yaml
```

---

### Q: How do containers share volume?
**A:** Same volume name, mount in both:
```yaml
volumes:
- name: shared-data
  emptyDir: {}

containers:
- name: main
  volumeMounts:
  - name: shared-data
    mountPath: /data

- name: logger
  volumeMounts:
  - name: shared-data
    mountPath: /data
```

---

### Q: How to verify both containers working?
**A:**
```bash
# Check pod status
kubectl get pod sidecar
# 2/2 Running = both containers up

# Check volume in each
kubectl exec sidecar -c main -- ls /data
kubectl exec sidecar -c logger -- ls /data
```

## Key Patterns

# Multi-container workflow
